# Zombas — Portal do sobrevivente

Portal público do servidor cooperativo Zombas: guia do novato, guia do veterano, regras e a lista
atual de mods.

- Site: https://kauehorta.github.io/zombas/
- Guia do novato: https://kauehorta.github.io/zombas/novatos/
- Guia do veterano: https://kauehorta.github.io/zombas/veteranos/
- Regras: https://kauehorta.github.io/zombas/regras/
- Mods atuais: https://kauehorta.github.io/zombas/mods/

O repositório contém o código-fonte e a versão estática servida diretamente pelo GitHub Pages.

**Antes de mexer na estrutura, na voz ou no layout, leia [DECISIONS.md](DECISIONS.md).** Registra
por que o site é dividido do jeito que é, a voz narrativa (e a personagem Residente Ivo), e as
decisões de gestão do repositório — evita redescobrir ou contradizer sem querer o que já foi
decidido.
